<section class="mb-space-xl">
<div class="flex items-center gap-space-sm mb-space-sm">
<span class="font-label-sm text-label-sm text-primary font-bold">§ 03</span>
<h2 class="font-headline-lg text-headline-lg text-on-surface font-bold tracking-tight">Empirical Rules for Maximum Retention</h2>
</div>
<p class="font-body-md text-body-md text-on-surface-variant leading-relaxed mb-space-md">
        An algorithmic scheduler is only as valid as the integrity of the data input provided during active study intervals. Cognitive research mandates four primary tenets:
      </p>
<div class="grid grid-cols-1 md:grid-cols-2 gap-space-md">
<!-- Rule 1 -->
<div class="p-space-md rounded-xl bg-surface-container-lowest shadow-sm flex flex-col justify-between">
<div>
<div class="flex items-center gap-2 mb-1.5">
<span class="font-label-sm text-label-sm font-bold text-primary">01</span>
<h3 class="font-headline-sm text-headline-sm text-on-surface font-semibold">Atomic Knowledge Formulations</h3>
</div>
<p class="font-body-sm text-body-sm text-on-surface-variant leading-relaxed">
              Every card must encode a singular proposition. Conflating multiple facts into a single prompt induces interference, producing ambiguous retrieval grades and breaking the mathematical model.
            </p>
</div>
<div class="mt-space-sm pt-space-xs font-label-sm text-label-sm text-on-surface-variant">Principle of Minimal Information (Wozniak)</div>
</div>
<!-- Rule 2 -->
<div class="p-space-md rounded-xl bg-surface-container-lowest shadow-sm flex flex-col justify-between">
<div>
<div class="flex items-center gap-2 mb-1.5">
<span class="font-label-sm text-label-sm font-bold text-primary">02</span>
<h3 class="font-headline-sm text-headline-sm text-on-surface font-semibold">Desirable Difficulty</h3>
</div>
<p class="font-body-sm text-body-sm text-on-surface-variant leading-relaxed">
              Cognitive effort correlates directly with long-term synaptic retention. Easy recognition tasks (e.g. passive re-reading) yield rapid decay, whereas effortful generative recall maximizes durability.
            </p>
</div>
<div class="mt-space-sm pt-space-xs font-label-sm text-label-sm text-on-surface-variant">Bjork Retrieval Hypothesis (1994)</div>
</div>
<!-- Rule 3 -->
<div class="p-space-md rounded-xl bg-surface-container-lowest shadow-sm flex flex-col justify-between">
<div>
<div class="flex items-center gap-2 mb-1.5">
<span class="font-label-sm text-label-sm font-bold text-primary">03</span>
<h3 class="font-headline-sm text-headline-sm text-on-surface font-semibold">Binary Retrieval Truthfulness</h3>
</div>
<p class="font-body-sm text-body-sm text-on-surface-variant leading-relaxed">
              Grading near-misses as "Remember" corrupts spacing intervals, forcing premature advancement of poorly formed traces. In algorithmic spacing, any hesitance should be classified conservatively.
            </p>
</div>
<div class="mt-space-sm pt-space-xs font-label-sm text-label-sm text-on-surface-variant">Cognitive Calibration Standard</div>
</div>
<!-- Rule 4 -->
<div class="p-space-md rounded-xl bg-surface-container-lowest shadow-sm flex flex-col justify-between">
<div>
<div class="flex items-center gap-2 mb-1.5">
<span class="font-label-sm text-label-sm font-bold text-primary">04</span>
<h3 class="font-headline-sm text-headline-sm text-on-surface font-semibold">Exponential Interval Expansion</h3>
</div>
<p class="font-body-sm text-body-sm text-on-surface-variant leading-relaxed">
              Linear interval increases lead to review over-saturation. True asymptotic consolidation demands that successive review intervals grow geometrically according to individual card stability.
            </p>
</div>
<div class="mt-space-sm pt-space-xs font-label-sm text-label-sm text-on-surface-variant">FSRS Geometric Curve Model</div>

      // Add connecting line to pending empty slot
      const nextTransition = document.createElement('div');
      nextTransition.className = 'flex items-center gap-1 flex-shrink-0 px-1 text-on-surface-variant font-body-sm text-body-sm';
